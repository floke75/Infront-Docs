# AlertTriggerType

Options for reactivating the alert after it has been triggered.

### Enumeration Members

#### TriggerDaily

```ts
TriggerDaily: "TriggerDaily"
```

Trigger no more than once per day

#### TriggerOnce

```ts
TriggerOnce: "TriggerOnce"
```

Disable alert after it has triggered
