# AnalyticscalculationsBetaResult

Calculation result of the levered beta, which is calculated according to:
levered beta = Cov(X,Y) / Var(Y)
where X refers to the quotes of the given security and Y to the quotes of the reference (compared) security, i.e., another instrument or the so-called country index of the provided security
