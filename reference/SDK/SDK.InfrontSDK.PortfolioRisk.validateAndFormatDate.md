# validateAndFormatDate

```ts
validateAndFormatDate(input: unknown): string
```

Validates if the input is a valid Date object and returns it as a string in ISO format.

#### Parameters

- input: unknown

  The value to validate and format.

#### Returns string

The date as a string in ISO format if valid, otherwise undefined.
