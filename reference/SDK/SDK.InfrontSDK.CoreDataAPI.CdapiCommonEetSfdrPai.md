# CdapiCommonEetSfdrPai

EetSfdrPai holds SFDR Principal Adverse Impact (PAI) indicators for a financial product.
PAI indicators measure the negative effects of investment decisions on sustainability factors.
Mandatory PAIs 01-18 are available via the 'mandatory' field parameter;
all others via 'optional'. Sources: WM, INFRONT, CLARITY.
