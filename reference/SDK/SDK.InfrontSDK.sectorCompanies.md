# sectorCompanies

```ts
sectorCompanies(options: SectorCompaniesOptions): DataRequest
```

Request from core data api a list of companies for a sector or sub-sector with some filters applied.

Sector, sub-sector and Filters are set in the options.

#### Parameters

- options: [SectorCompaniesOptions](./SDK.InfrontSDK.SectorCompaniesOptions.md)
