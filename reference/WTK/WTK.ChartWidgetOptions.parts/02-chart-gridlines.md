### Chart-Navigator

#### `Optional` hasNavigatorScroll

```ts
hasNavigatorScroll?: boolean = true
```

Enables scrolling the visible zoomed period via the mouse wheel when the navigator is present.

If set to `true`, a mouse wheel listener is attached to the chart container allowing the user
to scroll horizontally through the currently zoomed date range (using [navigatorScrollFactor](#navigatorscrollfactor) as step size).

If set to `false`, the mouse wheel listener is removed / not attached and regular page scrolling occurs.

##### Remarks

Only has an effect when both [showNavigator](#shownavigator) is `true` and [navigatorScrollFactor](#navigatorscrollfactor) is a valid number > 0.

##### Default Value

`true`

#### `Optional` navigatorScrollFactor

```ts
navigatorScrollFactor?: number = 0.2
```

Defines the relative scroll factor when using the mouse wheel to scroll through the period
while being in a zoomed period state.

As a basis it takes the currently zoomed interval and multiplies it by the set factor.

A factor of `1` will basically set the new start-date (xAxis extreme on the left, “min”)
to the previous end-date (xAxis extreme on the right, “max”).

It’s advised to only use values between 0 and equal or below 1 `(0 < x <= 1)`.

Everything beyond a factor of 1 will cause the scrolling to skip time intervals.

##### Default Value

`0.2`

#### `Optional` showNavigator

```ts
showNavigator?: boolean = false
```

Defines whether or not the Chart-Navigator is available below the Chart.

The navigator can be used to flexibly zoom in and out of a period, changing the xAxis extremes
and altering the start- and end-date within the given period.

It comes with two handles to manipulate either start-/end-date.
(Left handle = start-date, Right handle = end-date)

Futhermore the whole navigator bar can be dragged, manipulating both dates simultaneously
with the same delta.

Can be toggled in the Global-Settings Menu (TopToolbar)

##### Default Value

`false`

### Chart-Series

#### `Optional` areaStacking

```ts
areaStacking?: "percent" | "normal"
```

Enables area stacking for area-type charts. When set, each series is drawn as a filled
area stacked on top of the previous one.

- `'normal'`: stacked by absolute value; Y-axis shows the cumulative sum of all series.
- `'percent'`: stacked as a proportion of total; Y-axis is always 0–100%.
- `undefined` (default): stacking is disabled.

**Restrictions - the following are enforced automatically when stacking is active:**

- All instrument series are rendered as `area` type regardless of ` chartType`.
- Ordinate scaling is forced to `ABSOLUTE` (` compare` mode is incompatible with stacking).
- The Y-axis minimum is forced to `0`; for `'percent'` the maximum is forced to `100`.
- Streaming updates are suppressed (push data cannot be stacked correctly in real time).
- Data grouping (resolution aggregation) is disabled per series.
- The Highcharts navigator series inherits no stacking to prevent display artefacts.

**Recommendations for correct visual output:**

- Use at least two instruments; stacking a single series has no visual meaning.
- All instruments should be traded in the same currency so that absolute values are comparable.
- Disable the opposite ordinate (`showOppositeOrdinate: false`); a relative left axis is
  meaningless when Y values are forced to absolute stacked totals.

Can also be changed at runtime via ChartWidget.setAreaStacking.

##### Default Value

`undefined`

#### `Optional` chartType

```ts
chartType?: ChartType = ChartWidgetConstants.kDefaultChartType
```

Defines the global chart type which is applied to all instruments initially.

Chart types can be used to visualize the chart-data in different ways and thus allows for distinct analysis use cases.
E.g. Candlestick can be used to gain information about the volatility within a single data point (depending on the resolution).

Can be changed globally in the Chart-Type DropDown (TopToolbar).

- Can be changed for a single instrument in its Instrument-Settings Menu (Chart-Legend).

##### See

[ChartType](../WTK.ChartType.md)

##### Default Value

`'line'`

#### `Optional` colors

```ts
colors?: string[]
```

Defines the colors for each [ChartWidgetOptions.instruments](#instruments) Chart-Series.

If set, this option overwrites the colors set by stylesheets!

The first color string correlates to the first instrument series in the chart.
When the last color of the colors-list has been taken, the next instrument restarts with the first color.

Expects a valid CSS color format string.

##### Example

```css
'black', '#ffffff', 'rgb(2555,255,255)', 'rgba(255,255,255,1)', 'hsl(120,100%,50%)', 'hsla(120,100%,50%,0.3)'
```

Can be toggled globally in the Global-Settings Menu (TopToolbar)

- Can be toggled for each instrument in its Instrument-Settings Menu (Chart-Legend)

##### Default Value

`false`

#### `Optional` adjustSplits

```ts
adjustSplits?: boolean = true
```

Defines whether or not splits should initially be taken into account
when requesting Chart-Data for Instruments.

A split is an administrative and artificial mean by the corporation to change the ratio
between its share’s value and the amount.
If the value is halfed, then the amount of shares will be doubled.

The opposite is called reverse-split.

Can be toggled globally in the Global-Settings Menu (TopToolbar)

- Can be toggled for a single instrument in its Instrument-Settings Menu (Chart-Legend)

##### Default Value

`true`

#### `Optional` calendarFeeds

```ts
calendarFeeds?: number[] = []
```

Defines which Feeds should be taken to request Corporate Calendar Events from.
Acts as a filter.

If set to `[]`, undefined or ` null`, no filter is applied. Data from all sources are being requested.

##### Default Value

`[]`

#### `Optional` companyEventSmallDots

```ts
companyEventSmallDots?: boolean = false
```

Defines whether or not the markers of the Release Chart-Series should have
a smaller size with no label.

Not changeable in runtime

##### Default Value

`false`

#### `Optional` showCalendar

```ts
showCalendar?: boolean = false
```

Defines whether or not Calendar-Events Chart-Series should initially be displayed
for each Instrument Chart-Series.

Causes markers on the Instrument Chart-Series to appear that indicate the occurrence of a corporate calendar event.

Can be toggled globally in the Global-Settings Menu (TopToolbar)

- Can be toggled for a single instrument in its Instrument-Settings Menu (Chart-Legend)

##### Default Value

`false`

#### `Optional` showDividends

showDividends?: boolean = false

Defines whether or not Dividend-Distribution Chart-Series should initially be displayed
for each Instrument Chart-Series.

Causes markers on the Instrument Chart-Series to appear that indicate the occurrence of a dividend distribution.

Can be toggled globally in the Global-Settings Menu (TopToolbar)

- Can be toggled for a single instrument in its Instrument-Settings Menu (Chart-Legend)

##### Default Value

showSplits?: boolean = false

### Currency

#### `Optional` defaultCurrency

```ts
defaultCurrency?: string | Currency = Currency.DEFAULT
```

Defines the initial currency to be used for all instruments.

If the options is not set/set to `undefined` or ` null`, the currency of the instruments origin is used (exchange).

Can be changed globally in the Currency DropDown

- Can be changed for a single instrument in the Instrument-Settings Menu (Chart-Legend)

##### See

[Currency](../WTK.Currency.md)

##### Default Value

`Currency.DEFAULT`

#### `Optional` selectableCurrencies

```ts
selectableCurrencies?: SelectableCurrencies | (string | Currency)[] = ...
```

Defines the list of currencies that are available for currency conversion in the Currency DropDown (TopToolbar).

Allows for a collapsable folder structure/hierarchy, meaning that currencies can be grouped below different categories.

##### See

[SelectableCurrencies](../WTK.SelectableCurrencies.md) | [Currency](../WTK.Currency.md) | [SelectableIcon](../WTK.SelectableIcon.md) | [COLLAPSABLE](../WTK.COLLAPSABLE.md)

##### Default Value

`Currency.DEFAULT`
