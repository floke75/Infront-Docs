Defines whether or not the cursor events (mouseover/hover) are initially enabled or not.

#### `Optional` hasNavigatorScroll

```ts
hasNavigatorScroll?: boolean = true
```

Enables scrolling the visible zoomed period via the mouse wheel when the navigator is present.

If set to `true`, a mouse wheel listener is attached to the chart container allowing the user
to scroll horizontally through the currently zoomed date range (using [navigatorScrollFactor](#navigatorscrollfactor) as step size).

If set to `false`, the mouse wheel listener is removed / not attached and regular page scrolling occurs.

##### Remarks

Only has an effect when both [showNavigator](#shownavigator) is `true` and [navigatorScrollFactor](#navigatorscrollfactor) is a valid number > 0.

##### Default Value

`true`

#### `Optional` showNavigator

```ts
showNavigator?: boolean = false
```

Defines whether or not the Chart-Navigator is available below the Chart.

The navigator can be used to flexibly zoom in and out of a period, changing the xAxis extremes
and altering the start- and end-date within the given period.

It comes with two handles to manipulate either start-/end-date.
(Left handle = start-date, Right handle = end-date)

Futhermore the whole navigator bar can be dragged, manipulating both dates simultaneously
with the same delta.

Can be toggled in the Global-Settings Menu (TopToolbar)

##### Default Value

`false`

#### `Optional` showPulseTrackLine

```ts
showPulseTrackLine?: boolean = false
```

Defines whether or not a dashed, arrow-tipped line is drawn from the currently-hovered point on
a series to that series' current price (the last VISIBLE point - i.e. it follows the visible
navigator/scrollbar range, not necessarily the true last data point overall - at the right edge
of the plot area, same reference the Chart-Series label uses). The line updates live as the last
visible price streams in.

##### Default Value

`false`

#### `Optional` topToolbarLabels

```ts
topToolbarLabels?: TopToolbarLabels = {}
```

Overrides labels for top toolbar elements.

Currently supported overrides: chartTypeMenu, periodMenu, resolutionMenu, indicatorMenu, annotationMenu, templateMenu, compareMenu, newCompareMenu, currencyMenu

##### Example

```ts
{
      newCompareMenu: {
         isIcon: true,
         value: new InfrontUtil.Observable(Icon.getSvgIcon('chart')),
     }
      periodMenu: {
         isIcon: false,
         value: new InfrontUtil.Observable("Period"),
     }
},
```

##### See

[TopToolbarLabels](../WTK.TopToolbarLabels.md) | [DropDownSelectedItem](../WTK.DropDownSelectedItem.md)

##### Default Value

`object`

#### `Optional` watermarkCustomText

```ts
watermarkCustomText?: string
```

Defines which custom watermark text to be initially displayed in case the watermarkType is set to `'custom'`.

Can be changed in Global-Settings Menu (TopToolbar)

##### Default Value

`undefined`

#### `Optional` watermarkMaxFontSize

```ts
watermarkMaxFontSize?: number = 140
```

Defines watermark maximum font size. Will be scaled down for smaller charts.

##### Default Value

`140`

#### `Optional` watermarkMaxHeightPercent

```ts
watermarkMaxHeightPercent?: number = 30
```

Defines watermark maximum height in percentage of the chart height.

Senseful values are between 20 and 60.

##### Default Value

`30`

#### `Optional` watermarkMaxWidthPercent

```ts
watermarkMaxWidthPercent?: number = 70
```

Defines watermark maximum width in percentage of the chart plot width.

Senseful values are between 40 and 80.

##### Default Value

`70`

#### `Optional` watermarkType

```ts
watermarkType?: WatermarkType = WatermarkType.NONE
```

Defines which watermark type should be used initially in the background of the main Chart-Pane.

##### See

[WatermarkType](../WTK.WatermarkType.md)

##### Default Value

`'none'`

### Volume

#### `Optional` showVolume

```ts
showVolume?: boolean = false
```

Defines whether or not the Volume Chart-Series for the Main-Instrument
is initially active in the main Chart-Pane.

Can be toggled for the Main-Instrument in the Indicator DropDown (TopToolbar)

- Can be toggled in its Instrument-Settings Menu (Chart-Legend)

##### Default Value

`false`

#### `Optional` showVolumeUnderlay

```ts
showVolumeUnderlay?: boolean = false
```

Defines whether or not the Volume Chart-Series for the Main-Instrument
is initially active (in a split Chart-Pane).

Can be toggled for the Main-Instrument in the Indicator DropDown (TopToolbar)

- Can be toggled for a single instrument in its Instrument-Settings Menu (Chart-Legend)

##### Default Value

`false`

#### `Optional` volumeAlpha

```ts
volumeAlpha?: string = 'AA'
```

Defines the alpha value (transparency) for all Volume Chart-Series.

Expects a string consisting of two hexadecimal characters: `'00', 'FF'`

Can be changed for a single Volume Chart-Series in its linked Instrument-Settings Menu (Chart-Legend).

##### Default Value

`'#E95C3BDD'`

#### `Optional` volumeNegativeColor

```ts
volumeNegativeColor?: string = ...
```

Defines the color of a negative Volume Chart-Series bar.

Requires Up/Down colors to be enabled.

Expects a valid CSS color format string including alpha-channel.

Can be changed for a single Volume Chart-Series in its linked Instrument-Settings Menu (Chart-Legend).

##### Default Value

`'#E95C3BDD'`

#### `Optional` volumePositiveColor

```ts
volumePositiveColor?: string = ...
```

Defines the color of a positive Volume Chart-Series bar.

Requires Up/Down colors to be enabled.

Expects a valid CSS color format string including alpha-channel.

Can be changed for a single Volume Chart-Series in its linked Instrument-Settings Menu (Chart-Legend).

##### Default Value

`'#4DC46DDD'`

#### `Optional` volumeType

```ts
volumeType?: VolumeType = VolumeType.TURNOVER
```

Defines which data basis is used for all Volume Chart-Series.

Can be toggled for the Main-Instrument in the Indicator DropDown (TopToolbar)

- Can be toggled for a single instrument in its Instrument-Settings Menu (Chart-Legend)

##### See

[VolumeType](../WTK.VolumeType.md)

##### Default Value

`'TURNOVER'`
