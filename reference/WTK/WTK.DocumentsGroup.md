# DocumentsGroup

Enumeration type to set documents grouping. See [DocumentsWidgetOptions.group](./WTK.DocumentsWidgetOptions.md#group)

### Enumeration Members

#### Author

```ts
Author: "author"
```

Group by document author.

#### Country

```ts
Country: "country"
```

Group by country.

#### Language

```ts
Language: "language"
```

Group by document release language.

#### None

```ts
None: "none"
```

No grouping.

#### Type

```ts
Type: "type"
```

Group by document type. See InfrontSDK.DocumentType
