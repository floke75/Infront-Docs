# MarketToggleComponent

```ts
MarketToggleComponent: OrderEntryPredefined & { predefinedType: "marketToggle" }
```

Toggle for switching between different market order behaviors or routing options.
Specific behavior depends on broker implementation.

#### Type Declaration

- ##### predefinedType: "marketToggle"

  Identifies this as a market order behavior toggle component.
