# InstrumentSearchComponent

```ts
InstrumentSearchComponent: OrderEntryPredefined & {
    predefinedType: "instrumentSearch";
}
```

Search input and picker for selecting trading instruments.
Provides autocomplete and filtering capabilities across available markets.

#### Type Declaration

- ##### predefinedType: "instrumentSearch"

  Identifies this as an instrument search component.
