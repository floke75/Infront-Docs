# OrderSummaryComponent

```ts
OrderSummaryComponent: OrderEntryPredefined & { predefinedType: "orderSummary" }
```

Displays a comprehensive summary of the order before submission.
Shows all order parameters, estimated costs, and validation warnings.

#### Type Declaration

- ##### predefinedType: "orderSummary"

  Identifies this as an order summary display component.
