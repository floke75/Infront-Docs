# removeWhitespaces

```ts
removeWhitespaces(str: string): string
```

Removes all whitespaces of a given string.
Useful for appending strings to CSS classes.

#### Parameters

- str: string

  The string to replace the whitespaces in

#### Returns string

The string without whitespaces
