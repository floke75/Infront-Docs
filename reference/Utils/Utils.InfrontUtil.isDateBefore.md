# isDateBefore

```ts
isDateBefore(dateA: Date, dateB: Date): boolean
```

Check if dateA is before dateB. It compares only the date part of the dates, not time.

#### Parameters

- dateA: Date
- dateB: Date

#### Returns boolean

true if dateA is before dateB, else false
