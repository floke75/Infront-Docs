# toCamelCase

```ts
toCamelCase(text: string, usePascalCase?: boolean): string
```

Convert the passed text to camel case. Input phrase can be a normal phrase that uses spaces to separate words, snake case that uses _ as word separator or it uses - as a separator.

#### Parameters

- text: string

  Input text to be converted to camel case.
- usePascalCase: boolean = false

  Specify initial uppercase letter. [Read more]([https://en.wikipedia.org/wiki/Camel_case#:~:text=Camel case (stylized as camelCase,word starting with either case.)](https://en.wikipedia.org/wiki/Camel_case#:~:text=Camel%20case%20(stylized%20as%20camelCase,word%20starting%20with%20either%20case.))

#### Returns string
