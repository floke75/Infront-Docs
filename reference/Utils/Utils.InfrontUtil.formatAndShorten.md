# formatAndShorten

```ts
formatAndShorten(val: any, nb: number): string
```

Formats the value as an integer, but shortens it with k or m (or other letters specified in the language-dictionary):
Otherwise just format as integer.

#### Parameters

- val: any
- nb: number

#### Returns string
