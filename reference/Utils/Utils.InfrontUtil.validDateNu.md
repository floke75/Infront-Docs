# validDateNu

```ts
validDateNu(dateNu: number): boolean
```

Check if the date nu has correct format.

#### Parameters

- dateNu: number

  Numeric value used to represent the date value formatted as yyyymmdd.

#### Returns boolean

true if the date is correctly formatted.
