# isDateAfter

```ts
isDateAfter(dateA: Date, dateB: Date): boolean
```

Check if dateA is after dateB. It compares only the date part of the dates, not time.

#### Parameters

- dateA: Date
- dateB: Date

#### Returns boolean

true if dateA is after dateB, else false
