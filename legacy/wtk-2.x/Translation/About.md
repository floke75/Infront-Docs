# Translation

A language dictionary is specified in two levels, a category and a key. The table below shows all keys with the default values, sectioned by category.

Press **New** to create a new column where you can enter translated strings. Put the *[two letter ISO-code for the language](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2)* in the small text-box at the top
of the column.

To continue work on a file *previously created by this tool*, you can load it through the file-selector.
