# Dependencies

Heads up! These docs are for v2. Check out the latest version of Infront Web Toolkit!

Infront Web Toolkit and Cell have no dependencies and can be used along with any known library or script.

The 3rd party [Highcharts](http://www.highcharts.com/) component requires [jQuery](http://jquery.com/), [Mootools](http://mootools.net/) or [Prototype](http://www.prototypejs.org/). More info can be found on [Highcharts official documentation](http://www.highcharts.com/docs).
